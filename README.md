# 大富翁2 Patch

> 《大富翁2》的修正檔。選好遊戲資料夾按一下，就能解鎖多人地圖的單人遊玩。

---

## 這是什麼

《大富翁2》有幾張地圖被標記為「多人競賽」，原版必須湊滿人數才能開局，一個人想跟電腦玩就是進不去。這個工具直接修正遊戲主程式 `RUN.EXE`，讓那些地圖也能單人對戰電腦。

它是 **Rich Patch Series** 的一員，與《大富翁3》的修正檔操作方式相同。

**主要功能**

- **解鎖多人競賽地圖**——多人地圖可以一個人玩，對手換成電腦。
- **自動備份**——動到的檔案都會先複製成 `.bak`；重複執行不會覆蓋最初的備份。
- **全程日誌**——每一步做了什麼、成功還是跳過，都顯示在視窗下方。

### 系統需求

| 項目 | 需求 |
| :--- | :--- |
| 作業系統 | Windows 10 以上（64 位元） |
| 其他 | WebView2 執行期，Windows 10/11 已內建 |
| 遊戲 | 已安裝的《大富翁2》，資料夾中要有 `RUN.EXE` |

| 遊戲版本 | 狀態 |
| :--- | :--- |
| Steam 典藏版 | 已實測確認 |

## 快速開始

1. 執行程式，會開啟一個小視窗。
2. 看一下上方的**遊戲目錄**是否正確——程式會自動帶入自己所在的資料夾。不對的話按「**瀏覽…**」選到《大富翁2》的安裝資料夾（就是有 `RUN.EXE` 的那層）。
3. 按「**開始**」。
4. 下方日誌會逐條顯示處理結果，跑完會跳出摘要視窗。整個過程約一秒。
5. 開遊戲，選一張多人地圖，現在可以單人開局了。

## 常見問題

#### 開啟時出現「Windows 已保護您的電腦」或防毒警告

這支程式使用自簽憑證，沒有向憑證機構購買，因此 Windows SmartScreen 會跳出警告。若你是從本專案的 [Releases](../../releases) 頁面下載的，可以點「其他資訊」→「仍要執行」。

不放心的話，Release 附有 `SHA256SUMS.txt`，可以比對確認檔案沒有被掉包：

```powershell
Get-FileHash .\RICH2_PATCH-v1.0.1-Portable.exe -Algorithm SHA256
```

#### 日誌顯示「找不到 RUN.EXE！請確認檔案在目標目錄。」

選到的資料夾不是遊戲主目錄。按「瀏覽...」重選，要選到**直接放著 `RUN.EXE` 的那一層**，不是它的上層資料夾。

#### 日誌顯示「找不到特徵碼或已修改」

代表這個位置已經改過了，或你的遊戲版本不在支援清單內。前者是正常的——重複執行本工具就會看到這個訊息，不會有問題。

#### 我可以重複執行嗎？

可以。第一次執行時會把 `RUN.EXE` 備份成 `RUN.EXE.bak`，之後再跑都不會覆蓋這個最初的備份，所以隨時可以還原回原版。

#### 怎麼還原成原版？

把遊戲資料夾裡的 `RUN.EXE.bak` 改名回 `RUN.EXE`（覆蓋掉已修改的那份）即可。
